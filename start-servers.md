

## Starting the Application

You need to run TWO servers for this application to work:

### Terminal 1 - Express Server (Backend)
```bash
cd server
npm start
```
This will start the Express API server on http://localhost:5000

### Terminal 2 - Next.js Server (Frontend)
```bash
npm run dev
```
This will start the Next.js application on http://localhost:3000

## Access the Application

Open your browser and go to: http://localhost:3000
